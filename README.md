# 🌱 Plantopia – All-in-One Plant & Gardening E-Commerce Platform

**Plantopia** is a Django-based e-commerce web application designed to bring all kinds of plants and gardening essentials together in one convenient online platform.

The main goal of Plantopia is to make plant shopping easier and more accessible for everyone, from beginners who want to start their first indoor garden to experienced gardeners looking for plants and gardening supplies.

Users can explore different plant categories, browse gardening products, manage their shopping carts, save favorite products to their wishlists, and access gardening-related content.

## 🎨 UI Design & Prototype

The initial user interface and visual design of Plantopia were created using Canva to establish a user-friendly and engaging shopping experience.

## 🎯 Project Objectives

Plantopia aims to:

- Create a centralized online marketplace for plants and gardening essentials.
- Make it easier for people to discover and purchase different types of plants.
- Provide a convenient shopping experience for plant lovers and gardening enthusiasts.
- Encourage indoor gardening, rooftop gardening, and green living.
- Help beginners discover the products and resources they need to start gardening.
- Bring plants, seeds, soil, fertilizers, and other gardening supplies together in one platform.

## 🛍️ Product Categories

The platform is designed to cover different gardening needs, including:

- **Indoor Plants:** Plants suitable for homes, offices, and indoor environments.
- **Outdoor Plants:** Various plants suitable for gardens and outdoor spaces.
- **Seeds:** Different types of seeds for growing plants.
- **Soil & Growing Mediums:** Soil and other materials required for healthy plant growth.
- **Fertilizers & Plant Care:** Products that help maintain healthy plants.
- **Gardening Accessories:** Essential tools and accessories for gardening.

## ✨ Key Features

- **Product Browsing:** Explore available plants and gardening products.
- **Product Categories:** Browse products based on different gardening needs.
- **User Authentication:** User registration and login functionality.
- **Shopping Cart:** Add and manage products before purchasing.
- **Wishlist:** Save favorite products for future reference.
- **Gardening Blog:** Access gardening-related articles and information.
- **Responsive Interface:** A user-friendly interface designed for convenient browsing across devices.

## 🛠️ Technologies Used

### Frontend
- **HTML5** – Structure and layout of web pages.
- **CSS3** – Styling, page layouts, and visual design.
- **JavaScript** – Client-side interactions and dynamic functionality.

### Backend
- **Python** – Core backend programming language.
- **Django** – Backend web framework for application logic, routing, authentication, and data management.

### Database
- **Django ORM** – Database interaction and data management through Django models.

### Design
- **Canva** – Used for UI design and visual design elements.
